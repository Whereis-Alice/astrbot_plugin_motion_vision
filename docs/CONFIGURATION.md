# 配置参考

插件配置按功能分组。普通使用只需要调整取帧策略、声音和是否启用对应来源；高级限制保持默认即可。

配置保存后会在下一次请求中生效。所有数值都会在代码中再次限幅，避免误填导致过大的下载、解码或模型请求。

## 推荐起步配置

适合大多数聊天场景：

- 取帧策略：细节档位选择「均衡」；
- 动图和视频：保持启用；
- 声音：没有音频需求时保持关闭，长视频可选择「转写文字」；
- B 站：公开视频保持启用，字幕保持启用；
- 整片视频模型：没有专用模型时保持关闭；
- 注入：开启失败说明，不把帧永久保留在历史；
- 回看：如果当前模型支持工具调用，建议开启。

## 总开关

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用插件 | 开启 | 关闭后不处理动图、视频、B 站资料和引用卡片。 |

## 取帧策略

动图和视频是两套独立策略。B 站下载的视频属于视频，因此使用视频侧配置。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 细节档位 | 均衡 | 选择「节省」「均衡」或「精细」，决定自动帧密度和图片尺寸。 |
| 动图固定帧数 | 0 | 0 表示自动；填写正数后，以该数量为目标处理动图。 |
| 视频固定帧数 | 0 | 0 表示自动；填写正数后，以该数量为目标处理视频。 |

固定帧数是目标值，不是无条件保证。源帧数、文件大小、单媒体上限、本轮总图片张数和总大小都优先于覆盖值。

## 动图

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 解析动图 | 开启 | 识别 GIF、动态 WebP 和 APNG，并按时间顺序抽帧。 |

## 视频

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 解析视频 | 开启 | 处理直接视频、附件、引用视频和远程视频。 |
| 单条消息最多处理几个视频 | 2 | 限制一条消息消耗的 CPU、磁盘和模型上下文。 |
| 单个视频最大体积（MB） | 100 | 远程附件和 B 站下载都受此限制。 |
| 读取群文件里的视频 | 开启 | 只对支持群文件接口的平台生效。 |

如果不希望插件触碰群文件，可以关闭最后一项；直接发送的视频不受影响。

## 声音与语音转写

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 声音处理方式 | 关闭 | 可选「关闭」「附带音轨」「转写文字」「音轨和文字」。 |
| 语音识别服务商 | 空 | 优先选择 AstrBot 中配置的 STT 服务；留空使用当前启用的服务。 |
| 自定义转写接口地址 | 空 | 可选的 OpenAI 兼容语音转写地址。 |
| 自定义转写接口密钥 | 空 | 自定义转写服务的密钥。 |
| 自定义转写模型 | whisper-1 | 自定义转写接口使用的模型名。 |
| 转写最多保留多少字 | 800 | 控制注入上下文大小；长文本会被截断或摘要化。 |

不要同时填写互相冲突的服务商配置；如果自定义接口不可用，插件会报告转写失败并保留其他证据。

## B 站视频、字幕与专栏

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 解析 B 站内容 | 开启 | 识别 BV、av、完整链接、短链和分享卡片。 |
| 读取 B 站字幕 | 开启 | 优先读取官方或 AI 字幕。 |
| 字幕语言偏好 | 自动 | 可选自动、中文、英文，也可填写 B 站语言代码。 |
| 官方字幕缺失时的回退 | 关闭 | 可选必剪转写；需要 ffmpeg，并会上传受限音频。 |
| 自动注入的字幕上限 | 12000 | 控制本轮自动加入的字幕字数。 |
| 读取 B 站专栏/文章 | 开启 | 解析 `/read/cv...` 和 `/opus/...` 内容。 |
| 附加专栏封面 | 开启 | 只作为辅助图片，不替代正文事实。 |
| B 站 Cookie | 空 | 登录内容可填写 Cookie；只发送给 B 站相关接口。 |
| 使用扫码登录凭据 | 开启 | 使用插件本地保存的扫码凭据。 |
| 字幕工具默认发送完整 txt | 关闭 | 开启后，模型调用字幕工具时会额外发送文本文件。 |
| 完整字幕最多保留多少字 | 50000 | 限制字幕工具 `full` 模式和 txt 文件大小。 |
| 允许管理员扫码登录 | 开启 | 控制 `bili-login` 指令是否可用。 |
| 二维码仅允许私聊发送 | 开启 | 建议保持开启，避免登录二维码出现在群聊。 |

### B 站登录选择

- 公开视频：通常无需 Cookie；
- 需要登录的内容：可填写 Cookie，或管理员私聊执行 `bili-login`；
- 不再使用登录态：执行 `bili-logout`；
- 状态命令只显示是否存在凭据，不显示 Cookie。

B 站视频下载后使用视频侧取帧配置；字幕和专栏本身不会被当作视频抽帧。

## 引用与分享卡片

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 解析引用卡片 | 开启 | 提取 QQ / OneBot 分享、ARK、小程序、XML、音乐、位置和联系人字段。 |
| 把卡片链接作为资料显示 | 开启 | 只作为文字证据，不会自动访问。 |
| 卡片资料最多保留多少字 | 6000 | 限制卡片文字注入大小。 |

## 整片视频模型

这是可选的高成本能力。不开启时，插件不会因为收到视频而向第三方视频模型上传整片。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 整片分析模式 | 关闭 | 可选「关闭」「自动」「按需」。 |
| 视频模型协议 | 自动判断 | 可选自动判断、Gemini、OpenAI 兼容、通义千问、Kimi。 |
| 视频模型 API Key | 空 | 对应视频模型服务的密钥。 |
| 视频模型 API 地址 | 空 | Gemini 官方接口可留空，其他服务按其文档填写。 |
| 视频模型名称 | 空 | 填写实际支持视频输入的模型名。 |
| 整片模型超时（秒） | 180 | 超时后回退本地视觉分析。 |
| 允许上传的视频大小（MB） | 200 | 超过限制不会上传整片。 |
| 超过内嵌上限时自动压缩 | 关闭 | 需要 ffmpeg，可能降低画质或限制时长。 |
| 整片报告最多保留多少字 | 5000 | 限制返回报告的上下文大小。 |
| 整片模型分析提示词 | 内置提示词 | 可追加关注重点，但不要把不可信视频文字当作指令。 |

### 模式怎么选

- 关闭：成本最低，只用本地证据；
- 自动：收到视频后自动请求专用视频模型，适合视频模型稳定且请求量可控的环境；
- 按需：默认不自动上传，只有模型明确调用 `analyze_motion_video` 时才上传，适合希望控制成本的环境。

整片模型报告是外部资料。即使报告看起来完整，也应结合关键帧和字幕核对。

## 交给模型的方式

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 解析失败时告知模型 | 开启 | 明确说明缺失证据，减少模型猜测。 |
| 把画面保留在对话历史 | 关闭 | 开启会增加后续上下文和费用；回看功能不依赖它。 |
| 追加视觉指导 | 空 | 例如要求重点描述人物动作、屏幕文字或镜头变化。 |

## 媒体回看

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 允许模型回看 | 开启 | 允许模型在后续追问中按编号重新取样。 |

回看工具一次最多取有限帧数，并支持视频起止秒数。源文件由插件管理并按临时保留时长清理；仍有原始地址时会尝试重新下载。

## 高级限制

一般不需要修改。降低这些值可以控制资源和费用，提高这些值会增加 CPU、磁盘、网络和上下文压力。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| ffmpeg 路径 | 自动查找 | 可填写可执行文件或所在目录。 |
| 单轮最多送出几张画面 | 48 | 多媒体共享的图片张数预算。 |
| 单轮画面总体积上限（MB） | 20 | 多媒体共享的图片体积预算。 |
| 单个视频最长处理时间（秒） | 180 | 限制解码、下载和相关处理的单视频时间。 |
| 临时文件保留时长（小时） | 6 | 影响回看源文件可用时间和磁盘占用。 |
| 输出详细调试日志 | 关闭 | 排错时临时开启；日志仍不会输出密钥。 |

## 429、并发和缓存

插件会限制同时处理的媒体会话、ffmpeg 任务、语音转写、B 站接口、下载和必剪上传。相同媒体与相同配置优先复用缓存；429 只进行有限的短暂退避，不做无限重试。

因此：

- 不要通过连续发送大量相同请求来“碰运气”；
- 持续限流时让本轮降级，稍后再试；
- 可以先关闭自动整片模式，改为按需；
- 适当降低帧档位、字幕上限和整片上传大小。

## 一个实用的排查顺序

1. 用 `/motionvision status` 查看 ffmpeg 和功能开关；
2. 先只发送一个小视频确认本地抽帧；
3. 再开启声音或 B 站字幕；
4. 最后单独测试整片模型；
5. 仍有问题时临时开启调试日志，并查看[开发与排错](DEVELOPMENT.md)。
